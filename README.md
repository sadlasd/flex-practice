# Flex-практика

Мини-тренажёр CSS Flexbox на React. Нужно повторить образец из трёх блоков, выбирая направление, выравнивание и промежуток. Изменения сразу видны на экране.

[Демо](https://flex-practice-pakhomov.kibervanya.chatgpt.site) · [Репозиторий](https://github.com/sadlasd/flex-practice)

Демо в Sites пока доступно только владельцу. Репозиторий публичный.

## Возможности

- Шесть заданий: строка, центрирование, распределение по ширине, столбик и расположение в углах.
- Четыре свойства: `flex-direction`, `justify-content`, `align-items` и `gap`.
- Проверка расположения блоков и подсказка к каждому заданию.
- CSS текущего решения с кнопкой копирования.
- Сохранение отметок пройденных заданий в браузере.
- Адаптивная вёрстка.

## Стек

React, JavaScript, обычный CSS и Vite. Селекты, кнопки и блоки сверстаны без UI-библиотеки. Сервер и аккаунт для прохождения не нужны.

## Запуск

Нужен Node.js 22.12 или новее.

```sh
npm ci
npm run dev
```

Открой адрес из терминала.

```sh
npm run build    # сборка в dist
npm run preview  # просмотр сборки
```

## Структура

```text
src/
  App.jsx        — выбранное задание, настройки, проверка и прогресс
  Board.jsx      — контейнер с тремя блоками
  levels.js      — задания, свойства и функции проверки
  useFlexTool.js — необязательная интеграция с браузерным WebMCP
  main.jsx       — точка входа
  styles.css     — стили и мобильная версия
```

## Как устроена проверка

Один компонент `Board` рисует и образец, и результат. Они получают разные объекты со стилями. Настройки хранятся в `useState`, а ссылки на контейнеры — в `useRef`.

При проверке `getBoundingClientRect()` возвращает координаты блоков. Из координат каждого блока вычитаются координаты его контейнера. Если положение всех трёх блоков совпало с точностью до двух пикселей, задание засчитывается.

Проверяется расположение, а не точное совпадение CSS: иногда разные свойства дают одинаковый результат. Например, при `space-between` изменение маленького `gap` может не сдвинуть блоки.

Блоки намеренно имеют разные размеры, чтобы было видно работу `align-items`. Кнопка подсказки объясняет свойства на конкретном задании.

`useEffect` сохраняет только список пройденных заданий в localStorage. После перезагрузки настройки возвращаются к начальным значениям, а отметки остаются.

В браузерах с поддержкой WebMCP можно менять те же четыре свойства из чата. Хук `useFlexTool` отвечает только за эту необязательную интеграцию; в обычном браузере не включается.

## Ограничения

Прогресс хранится только в текущем браузере. Задания охватывают основы Flexbox: без `flex-wrap`, `order`, размеров гибких элементов и редактирования произвольного CSS. Копирование требует разрешения браузера; если оно недоступно, можно выделить код вручную.

## Ручная проверка

1. Нажать «Проверить результат» с начальными настройками: первое задание не должно засчитаться.
2. Выбрать `align-items: center` и `gap: 16px`: первое задание проходит.
3. Решить задание со `space-between`: маленькое изменение `gap` тоже может дать правильный макет.
4. Перезагрузить страницу: отметка пройденного задания сохраняется.
5. Проверить на телефоне: образец и результат выстраиваются друг под другом.
